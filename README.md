#                                       🌸 我的小工作台

一个不用花一分钱、能装进手机桌面的个人工作台。
选题、文案、搞钱项目、成长打卡，全在一个页面里。

---

## 一、怎么打开

**双击「启动.bat」**，浏览器会自动打开 `http://localhost:7788`。

第一次会自动抓一次热榜，几秒就好。关掉那个黑窗口就停止服务。

> 需要电脑装了 Node.js（免费）。如果没装，去 https://nodejs.org 下载 LTS 版，一路下一步。

### 手机怎么用

1. 电脑上双击「启动.bat」，**黑窗口不要关**
2. 黑窗口里会打印 `手机打开：http://192.168.x.x:7788`
3. 手机连**同一个 WiFi**，在浏览器输入这个地址

### 装到手机桌面（像个 App）

- **iPhone**：Safari 打开 → 底部「分享」→「添加到主屏幕」
- **安卓**：Chrome 打开 → 右上角 ⋮ →「安装应用」/「添加到主屏幕」

装好后有独立图标，全屏打开，没有浏览器地址栏。

> 想在外面（不限 WiFi）也能打开，看第六节「上云」。

## 二、每天早晨自动更新

网站的数据来自 `data/daily.json`（今日选题 + 三平台成稿 + 搞钱项目）。

每天早上 7:00 会自动跑一次：
1. 抓抖音 / B站 / 百度 / 头条的实时热榜
2. 从里面挑出适合普通人做内容的选题
3. 为每个选题写好公众号 / 小红书 / 视频号三版文案
4. 更新 8 个真实、低门槛、不卖课的搞钱项目
5. 写回 `data/daily.json`
6. 自动同步到线上地址

**没网 / 没抓到时，页面显示上一次的数据，不会白屏。**

首页右上角「🔄 换一批」可以随时手动更新一次。
「📈 实时热榜」是现抓的，点任意一条热词，直接按它写文案。

## 二·五、内容是怎么自动更新的（v1.1 起，链路已进仓库）

以前每天 7:00 的更新靠仓库外手工跑，现在全部收进代码里，**关掉浏览器也会更新**：

```
node scripts/gen-daily.js        抓热榜 → 生成 → 校验 → 原子写盘
```

服务启动后会自动调度：每天过了 `GEN_HOUR`（默认 7 点）且 `daily.json` 还是昨天的，就自动跑一次。
也可以手动触发：`curl http://localhost:7788/api/gen`（非本机调用要带 `?key=` 或 `x-api-key`）。

**三层保障，坏稿永远上不了线：**

| 层 | 做什么 | 失败时 |
|---|---|---|
| 校验 | 标题条数 == 正文条数、字数区间、段数、重复段、合规词、AI 味 | 有 error 直接中止 |
| 备份 | 写盘前把旧稿存成 `data/daily.json.bak` + `data/history/daily-日期.json` | 可随时回滚 |
| 原子写 | 写 `.tmp` → fsync → rename | 断电也不会留下半截 JSON |

**手工稿优先，模板稿兜底：**

- `data/daily.override.json` —— 你（或大模型）写好的人工稿放这里，**按标题精确匹配热榜选题**，命中就用你的稿子
- 没命中的选题由模板引擎现场生成，标 `source: template`（能发，但同赛道会撞结构，发之前改掉开头结尾）
- 自动生成**永远不会覆盖**已有人工稿：旧稿里的成稿会被自动收割进 override 层

**常用命令：**

```bash
npm run gen            # 生成今天的内容（当天已生成过会跳过）
npm run gen:dry        # 只校验不写盘，看会产出什么
npm run gen:offline    # 不联网，用本地 hot.json 生成
npm run validate       # 单独校验 data/daily.json
npm test               # 24 个回归测试，全离线
node scripts/gen-daily.js --force   # 强制重跑今天
```

### 选题池怎么用

1. 首页热榜每条右边有 ☆，点一下收进选题池（今日精选卡片上也有「📌 收进池」）。
2. 在选题池里点三个维度：**需求强 / 竞争小 / 能延展**，三个都点亮就优先写。
3. 点「📅 排期」挑一天，或者切到「日历」看排期。
4. 日历默认是**整月**（周一起头，前后补空），左右切上月/下月，点「本月」回来；
   想看细节就切「周视图」，一屏一天一格，能读到选题标题。
5. 排到今天的选题、昨天发了但没回填数据的，都会出现在首页「⏰ 今天要处理」里。
6. 日历格上会显示阳历、农历、节气节日，例如「7 / 九月廿九 / 立冬」——节日那天的格子会淡粉底；
   有排期或提醒的日子会多出小色条（手机端）或标题（电脑端）。

### 提醒怎么用

1. 「提醒与记录」→「＋ 新建提醒」，填一句标题、哪天、几点，可选每天/每周/每月重复，顺手写个备注。
2. 到点会弹网页通知（要先点「🔔 开启通知」）。**网页通知只在页面开着时有效。**
3. 想让关掉浏览器也能响：点「⤓ 导出到手机日历」，生成 `.ics` 后用手机系统日历打开导入，
   到点由系统提醒；选题池的排期和未来 60 天的节日也会一起带进去（节日提前 3 天提醒）。
4. 「记录」页每天一条，边写边自动保存，历史记录按天排好，导出 Markdown 时会一起带上。

### 手机端萌宠

手机右下角有只小猫，点它会说一句话：今天还剩几件事、池子里有几个选题，或者随机一句鼓励。
它是自己画的（纯 SVG + CSS，不联网、不加载图片、不占空间），呼吸、眨眼、摇尾巴都有。
「设置 → 🐾 桌面萌宠」可以关掉，关掉后会记住。

**为什么没直接用 GitHub 上的 DeepSeek 萌宠插件**：`dsh-pet`、`dsh-live2d-pets` 这类项目是
给 DeepSeek Harness / Electron 桌面端写的插件，依赖 Node 运行时和桌面窗口，没法塞进
纯静态 PWA；APK 里的 WebView 也没有系统悬浮窗权限。真要把宠物放到手机桌面之上，
得重打 APK 申请 `SYSTEM_ALERT_WINDOW` 做原生悬浮窗，代价大得多，所以先做了页内版本。

## 四、文案是怎么写出来的

### 先判断：这是「方法论」还是「观察评论」

这一步决定正文长什么样，比措辞重要得多：

| 类型 | 例子 | 正文是 |
|---|---|---|
| 方法论 | 怎么搞钱 / 怎么早起 / 怎么读书 | N 个**具体动作** |
| 观察评论 | 10 元快剪暴打设计总监 / 老人花钱请人陪聊 | N 个**判断和观察** |

同一套模板不可能同时写好这两类。所以引擎会先判断赛道，
再用完全不同的内容池、钩子、行动号召——你不能对一个社会现象说「明天照着做第一条」。

**目前 10 个赛道**：搞钱副业 / 职场打工 / 自我成长 / 读书学习 / 健康生活 /
生活方式 / 工具效率（这七个走方法论）+ 消费观察 / 社会话题 / 家庭情感（这三个走评论）。

### 结构

结构固定，按你说的来：

```
开头钩子（反差 / 情绪 / 悬念 / 故事）
   ↓
引导收藏
   ↓
中间：案例 + 故事 + 干货（标题说几条，正文就写几条）
   ↓
金句 / 引用
   ↓
行动号召 + 话题标签
```

- **数量严格对齐**：标题写「5 条大实话」，正文就是 5 条，不多一条不少一条
- **口语化**：短句、大白话、有具体的场景和对话，不像机器写的
- **不编数字**：效果类数字（赚了多少、涨了多少）系统不会瞎编，只写结构数（几条、几步）
- **必须原创**：热榜只用来找角度，正文是重新写的，不抄参考

### 想更像你自己？填素材库

「设置 → 我的素材库」填三样东西：

- **我的真实经历**：一行一个，比如「我去年在县城开过三个月奶茶店，赔了两万」
- **我见过的真实案例**：一行一个
- **我喜欢的金句**：一行一个

填完之后再生成，这些内容会直接进文案里，AI 味会掉一大半。
这是整套系统里**性价比最高的一步**。

## 八、安卓 APK（真·安装包）

项目根目录的 **`工作台-v1.0.apk`** 就是可以直接安装的安卓包（58 KB，自签名，Android 7.0+）。

它是网页的壳：启动后加载线上地址，所以内容和网站保持一致；抓不到网时显示内置离线页。

**装法**：把 apk 传到手机（微信「文件传输助手」发给自己最快）→ 手机点开 → 允许「未知来源安装」。

部署后也能直接用网址下载：`/apk`（server.js 里的固定入口，永远指向最新那个 apk）。

**和「加到手机桌面」的区别**

| | 加到桌面（PWA） | 装 APK |
|---|---|---|
| 怎么来 | 浏览器菜单里点一下 | 要传一个文件过来 |
| 数据 | 和浏览器同源 | **独立存一份**，与浏览器不互通 |
| 更新 | 打开就是最新 | 要重新装新版本 |
| 适合 | 自己日常用，最省事 | 要一个能转发的安装包 |

两边数据不互通，搬家用「我的文档 → 导出备份 / 导入备份」。

**重新打包**：`bash android/build.sh`（需要 `D:/android-sdk-zmt` 这套工具链，见脚本头部注释）。
源码在 `android/`，签名库是 `android/zimeiti.keystore`——**别丢**，换了签名就不能覆盖升级了。

## 九、常见问题

**Q：双击 bat 闪一下就没了？**
没装 Node.js。去 https://nodejs.org 装 LTS 版。

**Q：手机打不开？**
1. 手机和电脑必须连同一个 WiFi
2. 电脑上的黑窗口不能关
3. 公司/学校网络可能隔离设备，换手机热点试试

**Q：点「立即更新」没反应？**
断网或热榜接口被挡了。页面会用上一次的数据，过会儿再试。

**Q：数据会丢吗？**
浏览器清缓存会丢。养成每周「导出备份」的习惯。

**Q：自动生成的文案为什么读起来像模板？**
因为没命中 `data/daily.override.json`，走了模板引擎兜底（标 `source: template`）。
模板稿的三平台结构是固定的，同一赛道换话题会撞。想让稿子真的像你，两条路：
1. 往 override 里写人工稿（质量最高）
2. 往「设置 → 我的素材库」填真实经历，模板会把你的话拼进去

**Q：会不会自动更新把昨天的好稿子覆盖掉？**
不会。写盘前会把旧稿里的成稿自动收割进 `daily.override.json`，模板稿碰不到它们。
另外每次写盘前都备份到 `data/daily.json.bak`，标了日期的历史稿在 `data/history/`。

**Q：线上更新失败了怎么办？**
有 error 就中止，`data/daily.json` 一个字都不会动，页面继续用上一版。
看失败原因：`npm run gen:dry`（不写盘）+ `/api/health` 的 `genLast` 字段。

**Q：能换颜色吗？**
`assets/css/style.css` 最上面有一组颜色变量，改 4 个十六进制色值就能换整套配色。
